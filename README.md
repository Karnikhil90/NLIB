# NLIB

- Small **clang** library for learning purposes.
-  This project aims to replicate familiar structures from **Java** and **Python**, with a focus on an **ArrayList** and a **String** class. 
- Designed to ease the transition for developers coming from those languages.

- btw, Im learning c cuz i wanna make a OS for ESP32 and more such embedded system. And also a language.
---


To build the library, run:

```bash
make all
```

To run the examples, use:

```bash
make list
```

or 

```bash
make main
```
